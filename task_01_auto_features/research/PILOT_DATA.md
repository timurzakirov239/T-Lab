# Локальный пилот данных Yambda

Пакет подготавливает полную историю случайно выбранных пользователей из локального опубликованного набора `flat/50m`; обучение моделей не выполняется. Случайная выборка делается равновероятно по уникальному `uid` после первого прохода только по UID; активность не используется для выбора. Следующий проход фильтрует исходные строки по выбранным UID, сохраняя все столбцы и все события этих пользователей. Истории не обрезаются.

Выходы в `artifacts/pilot_001/data/`: `events.parquet`, mappings только по уникальным связям item/entity для встретившихся объектов, и `metadata.json`. Метаданные включают SHA256 исходника из манифеста, seed/UID, счётчики событий, временные границы в исходных timestamp units, проверку сортировки и равных UID+timestamp через границы batch, пропуски, proposed p30/p70/p85 границы, coverage и many-to-many по уникальным mapping links, версию среды и длительность. Протокол: `train_query_start_p30 <= t < train_end_p70`, validation `train_end_p70 <= t < validation_end_p85`, test `t >= validation_end_p85`; равные timestamp не разрываются. Временная семантика — proposed offline replay: logged event становится известен на своём timestamp, а до запроса доступны только события с `timestamp < t`. Timestamp остаются raw, календарная конверсия не делается.

Тесты на fixtures проверяют полную историю, ties на границе batch, хронологическую ошибку, дедупликацию links и корректную пустую mapping-таблицу при нулевом покрытии.

## Команды

Из `task_01_auto_features`:

```powershell
python src/pilot_data.py --users 64 --seed 20261025 --output artifacts/pilot_001/data
python -m unittest tests.test_pilot_data -v
```

Импортируемый интерфейс: `prepare_data(output: Path, users: int = 64, seed: int = 20261025) -> dict`. Полный режим читает UID-колонку источника для популяции, затем второй раз просматривает события с фильтрацией Arrow batches. Mappings фильтруются по множеству item IDs только пилотной выборки; глобальные наборы миллионов связей не создаются.

## Ограничения

Факт сохранения всех событий относится ко всем выбранным UID в локальном опубликованном файле 50M. Это не доказывает полноту истории относительно исходного Yambda-5B. Квантильные временные границы — предложенный протокол для пилота, а не утверждённое решение всего исследования. Результаты эксперимента ограничены сохранённым Parquet и metadata; модели/метрики не создаются.
