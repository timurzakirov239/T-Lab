## Проверка сохранённых результатов

Из корня репозитория, в окружении Python 3.12 с NumPy:

```powershell
python task_01_auto_features/src/verify_submission.py
```

Ожидаемый итог — `status: PASS` для P001, P006, P007 и P008. Проверка использует сохранённые ранги и манифесты, не читает исходные датасеты и не запускает обучение или повторную тестовую оценку.

Основной итоговый тест P006 не подтвердил преимущество Auto A2 над ручным UIDC. P007/P008 — дополнительные исследования на валидации; их результаты не заменяют основной тест. Точные числа, интервалы и ограничения приведены в итоговом отчёте.
