### Обнаруженные особенности

1. Отдельный файл репозитория `interactions.csv.zip` содержит 1 594 787 строк, тогда как `data_original.zip` содержит 5 476 251 строку взаимодействий. Для исследования используем взаимодействия из `data_original.zip`. Отдельная версия сохранена только для прослеживаемости в `raw/kion/reference_standalone/`; объединять её с основным файлом нельзя.
2. README источника указывает окончание периода в 2022 году, но максимальная дата в скачанном основном CSV — **2021-08-22**. Для разбиения опираемся на фактические данные и отдельно проверим это расхождение перед итоговым отчётом.
3. Число строк пользовательских метаданных меньше числа пользователей во взаимодействиях. При подготовке данных потребуется проверить покрытие и предусмотреть отсутствующие характеристики.
4. Поле времени называется `last_watch_dt` и содержит даты. В этой таблице нет отдельного столбца типа события и детального времени каждого просмотра. Перед построением временных агрегатов нужно выяснить семантику агрегированных значений `total_dur` и `watched_pct`; нельзя считать их детальным журналом событий без дополнительного обоснования.

- Источник: <https://huggingface.co/datasets/yandex/yambda>.
- Зафиксированная версия: `dd6f3a19eef5866e346c3270e098baa641a44948`.
- Выбран опубликованный вариант **50M**, формат `flat`, единая таблица всех типов событий.
- Локальное дополнительное сэмплирование событий не выполнялось.

| `artist_item_mapping.parquet` | 38 274 621 | Связи объектов с исполнителями |

Сохранены `SOURCE_README.md` и `LICENSE`. В лицензии источника указана Apache License 2.0. Карточка также содержит указание на научное и исследовательское использование.

Все три Parquet-файла совпали с опубликованными SHA256; проверены начальная и конечная сигнатуры `PAR1` и допустимый размер footer. При последующей metadata-инвентаризации через PyArrow проверены схема и число строк по footer: 47 790 449 событий, 9 271 906 строк artist mapping и 9 651 644 строк album mapping. Полное чтение строк не завершено. Подробности: [аудит](../research/data_audit.md), [артефакт](../artifacts/data_audit/metadata_audit.json).

По карточке источника Yambda-50M включает 10 000 пользователей. На этапе анализа проверим фактический состав и полноту истории относительно опубликованного варианта. Сохранность истории относительно полной версии 5B пока не установлена.

Полная версия 5B, дублирующие таблицы отдельных типов событий, последовательное представление и аудиоэмбеддинги не входят в выбранную загрузку. Для первой работы доступны события и связи с исполнителями/альбомами; необходимость дополнительных данных определим по постановке эксперимента.
