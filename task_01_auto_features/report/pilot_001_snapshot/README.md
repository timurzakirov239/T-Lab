# Замороженная контрольная точка P001

**Обязательно включить в итоговый отчёт работы 1** по прямому указанию пользователя
25 октября 2026 года. Git-тег исходного состояния: `p001-pilot-2026-10-25`.

Эти файлы — точные копии завершённого запуска `artifacts/pilot_001/`:
метрики, статус, описания построения признаков, результаты отдельных моделей
и metadata подготовки. `config.json`, протокол и рецензия также сохранены.
Не редактировать и не заменять их после новых экспериментов.

Полный оригинал данных пилота, запросов, моделей, predictions, исходного кода
и отчёта находится локально в `backups/P001_original_2026-10-25.zip`.
Архив не отправляется в GitHub. SHA256 архива и каждого его файла записаны
в `checkpoint_manifest.json`. Этот локальный архив защищает от перезаписи
при следующих запусках, но не заменяет внешнюю резервную копию диска.

Из корня проекта проверить контрольную точку:

```powershell
.\.venv\Scripts\python.exe task_01_auto_features/src/verify_pilot_checkpoint.py
```

После свежего Git clone доступны все 19 файлов компактных доказательств,
код и отчёт. Большие исходные датасеты, локальный архив, prepared Parquet,
модели и predictions в репозиторий не входят. Их наличие не заявляется
результатом одного только клонирования.

финальный test не оценивался. Указанные в исходном статусе абсолютные пути
относятся к машине первоначального запуска.
