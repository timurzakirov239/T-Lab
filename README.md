## Куда загружать данные

- Для первой работы: `task_01_auto_features/data/raw/kion/` или `task_01_auto_features/data/raw/yambda/`.
- Для второй работы: `task_02_rl_recommendations/data/raw/kion/` или `task_02_rl_recommendations/data/raw/yambda/`.

Достаточно выбрать **один** подходящий датасет для каждой работы. Загружать оба датасета для каждой работы не требуется. Если будем использовать один и тот же набор в обеих работах, повторно скачивать его не нужно: во второй работе настроим путь к уже загруженным данным.

Подробности: [DATASETS.md](DATASETS.md). Имена каталогов `kion` и `yambda` обозначают варианты, а не обязательство использовать оба.

## Структура каждой работы

- `assignment.txt` — исходное условие без изменений.
- `README.md` — разбор задачи и предварительный план исследования.
- `data/raw/` — исходные файлы и архивы.
- `data/processed/` — будущие подготовленные данные и разбиения.
- `src/` — будущий код обработки, обучения и оценки.
- `configs/` — будущие конфигурации экспериментов.
- `notebooks/` — будущий анализ данных и результатов.
- `artifacts/` — будущие модели, метрики и графики.
- `report/` — будущий итоговый отчёт.
