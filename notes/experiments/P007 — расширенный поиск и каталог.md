# P007 — расширенный поиск и каталог

## Вопрос

Пользователь попросил реализовать новые методы отбора, сравнить их, затем прогнать модели по всем доступным трекам. Проверяем Random206, Permutation206, Stable206, ForwardGroups66 против Manual I/UIDC и прежних A1/A2.

## Протокол

Только development t<23380165; P006 не переоткрывать. Те же три disjoint64, все499/514/518 validation queries. Full означает все доступные cohort items<t на этих1531 запросах, не все50M событий/10kUID. Отдельное обучение на глобальном каталоге в этот этап не входит.

Обучение одинаковое ограниченное K100, conditional на наличии target; полная оценка использует те же модели. Это catalog bridge с distribution shift, а не обучение на всех треках. Каталог cohort-local, mapping fixed snapshot. Поиск только inner-time, masks фиксируются до внешних predictions; actual fits/стоимость сообщаются отдельно.
